========================================
HOW TO OPEN:
========================================

Method 1 (Easiest):
- Double-click `run.py`

Method 2 (Alternative):
- Open the folder in your terminal
- Run `python main.py`


TROUBLESHOOTING:
- Check that Python is installed and added to your system PATH.
- Make sure `main.py`, `physics.py`, and `ui.py` are all in the same folder.
- Linux users: Run `sudo apt-get install python3-tk` if you get a GUI error.

========================================
  BALL IN A SPINNING CIRCLE - CONTROLS
========================================

MOUSE CONTROLS:
- Left-Click: Spawns a Repulsive Well (Red dashed ring) that pushes balls away.
- Right-Click: Spawns an Attractive Well (Cyan dashed ring) that pulls balls in.
  (Note: Maximum of 3 wells allowed at a time; oldest ones disappear automatically).

CONTROL PANEL WINDOW:
- Pause / Resume: Freezes or unfreezes the physics simulation.
- Summon: Instantly injects a batch of new balls into the center.
- KILL ALL BALLS: Clears all active balls and gravity wells.
- Advanced Toggle: Expands or collapses fine-tuned settings.

ADVANCED SETTINGS:
- Circle Rotation Speed: Controls how fast the boundary wall spins.
- Opening Hole Size: Adjusts the physical width of exit gaps.
- Number of Exits (Gaps): Sets the number of symmetrical gaps (1 to 5).
- Bounciness: Sets surface elasticity (> 1.0 adds energy, < 1.0 absorbs it).
- Color Schemes: Switch between Neon Mix, Fire, Matrix, Pastel, or Random.
- Toggles: Enable/disable Ball Collision, Motion Trails, and Dev Hitboxes.
- Max Ball Limit & Actions: Choose how the app handles overflow (Pause, Delete Oldest, or Stop Spawning).
